UDS – Order to Invoice Flow

From employee order → Location Admin → Company Admin → Vendor → GRN → Invoice → Payment (multiple companies, multiple vendors)

flowchart LR A[Employee\nOrders] --> B[Location Admin\nApprove] B --> C[Company Admin\nApprove] C --> D[Vendor\nFulfil] D --> E[GRN\nGoods Receipt] E --> F[Invoice\nCompany Approve] F --> G[Payment]

Steps (easy to follow)

  1. Employee – Places order from catalog, confirms address and submits.
  2. Location Admin – Sees order in Approvals, approves or rejects. Company Admin is notified.
  3. Company Admin – Sees order in Approvals, approves. Order status becomes “Awaiting fulfilment”. Vendor(s) are notified.
  4. Vendor – Receives order (indent), ships items, creates GRN (Goods Receipt Note).
  5. Company Admin – Approves GRN. Relevant parties are notified.
  6. Vendor – Raises Invoice. Company Admin approves invoice. Payment follows.
